# 🎓 EdTechPlatform — A Scalable Learning Management System

A web-based educational platform designed to support students, tutors, and administrators in managing courses, enrollments, and real-time communication. Built with HTML and JavaScript, this prototype lays the foundation for a feature-rich LMS.

---

## 🚀 Features

- 🧑‍🏫 Tutor and student registration flow  
- 📚 Course creation and enrollment tracking  
- 💬 Real-time chat functionality between users  
- 📄 Separate HTML views for courses, signup, student/tutor dashboards  
- 🔐 Basic authentication using middleware and route protection

## 🧠 Tech Stack

- HTML, CSS (inline)  
- Vanilla JavaScript  
- Node.js (Express-based server)  
- File-based routing  
- No external database (yet—add MongoDB or Firebase for scale)

---

## 📦 Getting Started

> _Note: This version may be intended as a static prototype. For deployment, server-side logic will need database integration and additional security._

### To Run Locally:
1. Clone the repo  
2. Unzip `EdTechPlatform.rar`  
3. Install dependencies: `npm install`  
4. Start the server: `node server.js`  
5. Open `index.html` or relevant pages in browser
